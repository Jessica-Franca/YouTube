# Mundo MIS — YouTube

Scripts e materiais das aulas do canal para você estudar junto com o vídeo.

Canal: [youtube.com/@mundomis](https://www.youtube.com/@mundomis)

## Comece por aqui

Não sabe por onde começar? Siga a **[trilha recomendada](./COMECE-POR-AQUI.md)** — ordem pedagógica (negócio → SQL → importar CSV → ETL), não a ordem das playlists.

## Como estudar

1. Abra o vídeo no YouTube  
2. Abra o material correspondente aqui no GitHub  
3. Pratique — a ideia é fazer, não só assistir  

**Assistir** sempre abre o vídeo específico (`watch?v=...`), não a playlist.
